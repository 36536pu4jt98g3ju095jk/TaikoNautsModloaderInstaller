TaikoNauts の MOD を動かす土台「ModLoader」と、演奏画面の背景に NULM を流す「NULM Background MOD」を、自動で導入するインストーラーです。

An installer that sets up the ModLoader (the base that runs TaikoNauts mods) and the NULM Background mod (plays NULM animations as the play-screen background) for you.

何をインストールするの?

What does it install?

下の 3 つを、まとめて用意します。どれも、チェックを外せば省けます。

The three things below. Untick any of them to skip it.

ModLoader

MOD を動かす土台

The base for mods

TaikoNauts に MOD を読み込ませる仕組みです。公式の ModLoader の最新版を入れます。

The mechanism that lets TaikoNauts load mods. The latest official ModLoader is installed.

NULM Background

背景に NULM を流す MOD

The NULM background mod

演奏画面の上背景・下背景に NULM アニメーションを流します。クリアすると fever 背景に変わります。

Plays NULM animations as the upper and lower play-screen backgrounds, and switches to fever when you clear.

Lumens

NULM の置き場所

Where NULM goes

使っているスキンの中に Lumens フォルダを作ります。中身は空です(NULM のデータは入れません)。

Creates a Lumens folder in the skin you use. It is empty; no NULM data is installed.

使い方

How to use it

最初に、TaikoNauts と Mod Manager を終了しておいてください。

First, close TaikoNauts and the Mod Manager.

1 2 3 4
1 2 3 4

  1. TaikoNauts.exe を選ぶ。

    「参照...」を押して、ゲームのフォルダにある TaikoNauts.exe を選びます。ウィンドウに、ファイルをドラッグ&ドロップしてもかまいません。前回選んだ場所は覚えています。

    Select TaikoNauts.exe.

    Press “Browse...” and pick TaikoNauts.exe in the game folder. You can also drop the file onto the window. The last choice is remembered.

  2. 入れるものを確認する。

    「状態」に、いま入っているものが出ます。ふだんは、すべてチェックしたままで大丈夫です。Lumens を作るスキンは、使用中のスキンが最初から選ばれています。

    Check what to install.

    “Status” shows what is already there. Usually leave everything ticked. The skin in use is preselected for the Lumens folder.

  3. 「インストール」を押す。

    ダウンロードと導入が進み、ログに経過が出ます。数分かかることがあります(ModLoader は約 63 MB)。「完了しました」と出れば終わりです。

    Press “Install”.

    It downloads and installs, and the log shows progress. It can take a few minutes (the ModLoader is about 63 MB). You are done when it says it finished.

  4. Lumens に NULM を置く。

    「Lumens フォルダを開く」で、置き場所が開きます。NULM のパックを入れて、ゲームを起動します。くわしくは 下の説明 へ。

    Put NULM packs in Lumens.

    “Open Lumens folder” opens the place. Add your NULM packs and start the game. See the next section.

すでに ModLoader が最新なら、ダウンロードし直しません。もう一度実行しても、config.json や、置いた NULM のパックは消えません。
If the ModLoader is already up to date it is not downloaded again. Running the installer again never removes your config.json or your NULM packs.

Lumens に NULM を置く

Putting NULM in Lumens

インストーラーが作った Lumens フォルダに、NULM のパックをパックごとに 1 つのフォルダで置きます。ゲームのスキンごとに別のセットを持てるので、スキンを切り替えると背景も変わります。

Put NULM packs in the Lumens folder the installer created, one folder per pack. Each skin can have its own set, so switching skins switches the backgrounds.

donbg_上背景Upper background
bg_nomal_下背景Lower background
bg_fever_fever 背景(クリア中に表示)Fever background (while cleared)
bg_dai_下背景の上の台Stand over the lower background

曲が始まるたびに、同じ種類のパックの中から 1 つがランダムに選ばれます。詳しい設定は、NULM Background の説明ページを見てください。

At the start of each song one pack of each kind is picked at random. For more settings see the NULM Background guide.

NULM のデータや画像は、このインストーラーには含まれていません。ご自身で用意できるものだけを使ってください。
This installer contains no NULM data or textures. Use only what you have the right to use.

安全面

Safety

  • ダウンロードするのは、ModLoader と NULM Background の公開リポジトリのリリースだけです。
  • ダウンロードしたファイルは、GitHub が公開している SHA-256 と照合します。一致しなければ破棄します。
  • TaikoNauts.exe は書き換えません。ModLoader の導入では、元の raylib.dll を raylib_original.dll にバックアップします。
  • 展開先のフォルダの外にファイルを書こうとするパッケージは拒否します。
  • 管理者権限は要求しません。現在のユーザーで動きます。
  • It downloads only releases of the public ModLoader and NULM Background repositories.
  • Each download is checked against the SHA-256 GitHub publishes; a mismatch is discarded.
  • TaikoNauts.exe is never modified. Installing the ModLoader backs up the original raylib.dll as raylib_original.dll.
  • A package that tries to write outside the target folder is rejected.
  • It does not ask for administrator rights and runs as the current user.

元に戻すには

To undo it

ゲームのフォルダの uninstall.bat を実行すると、元の raylib.dll に戻ります。NULM Background だけ外すなら、mods\nulm-background フォルダを削除します。

Run uninstall.bat in the game folder to restore the original raylib.dll. To remove only NULM Background, delete the mods\nulm-background folder.
